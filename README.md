# cw-core

Shared core library for agentic applications generated by `ai_agent_builder`.

Provides:
- `cw_core.utils` — config loading and logging setup
- `cw_core.context` — session/customer context helpers for agent prompts
- `cw_core.deterministic_flow` — deterministic workflow step instructions/loader
- `cw_core.tools` — shared ADK tools (state helpers, external REST tools, MCP tools)

## Installation

This is a private package, not published to PyPI. Consumers depend on it via a
pinned git tag:

```toml
dependencies = [
    "cw-core @ git+ssh://git@github.com/jsettypalli/cw-agent-core.git@v0.1.0",
]
```

## Versioning

Tag releases with semver (`vX.Y.Z`). Consuming projects pin an exact tag so new
releases don't silently affect already-generated/deployed agent applications.
